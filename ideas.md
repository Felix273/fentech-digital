# FenTech UI direction: Signal Grid

**References:** Better Stack, Penpot, and Sparkles DESIGN.md analyses from [getdesign.md](https://getdesign.md/), adapted rather than copied.

## Direction

A dark, technical observability-inspired interface for a Kenyan digital systems partner: calm, precise, high-contrast, and operationally credible. The existing FenTech content, CMS, routes, and brand mark remain the source of truth.

## Design movement

Move from a broad editorial agency layout toward a signal-driven systems interface: dark hero and footer, structured light surfaces, compact status labels, technical grid lines, restrained rounded cards, and a single vivid mint/cyan signal color for actions and proof points.

## Core principles

- Make the work feel measurable and dependable rather than decorative.
- Use contrast and hierarchy before adding ornament.
- Keep one strong action per visual region.
- Prefer dense, useful proof blocks over generic marketing flourishes.
- Preserve responsive behavior and accessible focus states.

## Color philosophy

- Ink: `#07111f` for navigation, hero, footer, and technical surfaces.
- Paper: `#f7faf9` for page background.
- Signal mint: `#9fffc8` for primary actions and active states.
- Cyan: `#5eead4` for links and small accents.
- Electric blue: `#6da8ff` for secondary emphasis.
- Slate text: `#536274` for supporting copy.
- Borders use cool, low-opacity lines rather than heavy shadows.

## Layout paradigm

Use a centered max-width system, generous gutters, thin rules, compact labels, and a responsive two-column hero. Add a subtle technical grid texture only on dark surfaces. Keep cards lightly rounded (10–16px) with hairline borders.

## Signature elements

- A small `LIVE SYSTEMS / NAIROBI` status pill in the hero.
- Signal-mint primary buttons with dark text.
- A hero “system pulse” panel that turns the existing 3D visual area into a framed, technical instrument.
- Section labels with a leading status dot and uppercase tracking.
- Proof cards with metrics, service categories, and arrow affordances.

## Menu treatment

The broader getdesign catalog treats navigation as a product-orientation moment rather than a utility drawer. FenTech's menu follows that principle with a full-screen technical panel: a clear `Explore FenTech` eyebrow, indexed primary routes, arrow affordances, one focused contact CTA, and a compact systems-status rail. Better Stack informs the operational status language, Penpot informs the grouped product-navigation hierarchy, and Sparkles informs the direct action-oriented CTA.

## Interaction and animation

Use short 180–260ms transitions, slight lift on cards, and a quiet pulsing status dot. Preserve reduced-motion support. No new heavy animation dependency.

## Typography system

Keep the existing Glacial Indifference font for brand distinctiveness. Use tighter display tracking, compact uppercase labels, and readable 17–19px body copy. Avoid oversized text that pushes meaningful content below the fold on mobile.

## Brand essence and voice

Practical, technically confident, locally grounded, and outcome-oriented. Copy should sound like a reliable systems partner, not a generic agency.

## Wordmark and signature color

Retain the existing FenTech wordmark. Signal mint is the new signature interaction color, used sparingly for primary actions, active navigation, proof dots, and focus-adjacent accents.
